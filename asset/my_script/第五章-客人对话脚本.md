# 《典当春秋》第五章 · 庚子（终章）—— 客人对话脚本

> 对应配置表：`第五章-客人与物品配置表.xlsx`（客人 C1xx 及回访者，物品 I5xx）。
> 时间：光绪二十六年（庚子，1900）五月十五 至 六月十九，共三十一天。
> 史实锚点：五月中旬拳民大批入津，焚教堂；五月廿一（第7天）大沽炮台失陷；五月廿五（第11天）朝廷对各国宣战；紫竹林租界激战；六月十三（第27天）聂士成战死八里台；六月十八（第30天）天津城陷；六月十九起（第31天）联军入城大掠。

## 结局判定

### 计算口径
- **信誉 / 江湖 / 官府**：全五章累计值（见各章数值汇总）。
- **义举**：收留沈墨、孙秀才出城、平价卖米、拳民借粮、托莫理循送走王约翰、替小凤仙赎身、赎翠儿出烟馆、施粥（任意一项算1）。
- **卖主砖**：第一章孙秀才报官、第二章名册报官、第三章报官沈墨/孙秀才/告发维新党、第五章刘头交拳民、第五章献清单（每项1，献清单算2）。

- **铺子状态**：第五章保库最终判定（保住 / 焚毁）；第四章是否被封铺。

### 结局一 · 庚子劫灰

**【画面】** 焦黑的门框。一块烧了一半的招牌：“恒裕”。
旁白：恒裕当烧了。烧掉的有当物、有账本、有当票。
旁白：那些把东西当在这里的人，再也赎不回来了。
- 若木匣内容已托出 → 旁白：可那三页账，没有烧。它在上海的报纸上，在横滨的报馆里，在一个笔帖式的怀里。
- 若木匣未托出 → 旁白：那只匣子，和师父的信，一起烧成了灰。
旁白：你在废墟里找到一只铜算盘。算珠都熔在了一起。
旁白：后来有人在北门外的粥厂里见过你。你在替人写当票——不收钱，只写“当期：太平之日”。
**【字幕】** 庚子年，天津城内房屋焚毁者，十之三四。

### 结局二 · 破产

**【画面】** 街角，一张破桌子，一杆旧戥子，一块木牌：“代当·估价”。
旁白：恒裕当的封条，到庚子年都没揭下来。
旁白：你在街角摆了个摊，替人估价，替人跑当铺。眼睛还是那双眼睛。
旁白：小顺子去码头扛活了。他每天收工，都来你的摊子坐一会儿。
旁白：师父说，眼睛是本钱。你还有本钱，只是没有了铺子。
**【字幕】** 光绪二十七年，有人在估衣街开了一家新当铺。掌柜的，是个年轻人。（隐藏结局线索：二周目继承“眼力”）

### 结局三 · 卖主求荣

**【画面】** 新修的门脸，金字招牌。门口挂着都统衙门发的“顺民”执照。

旁白：你的铺子里，再也没有人敲后门。
旁白：孙秀才没有回来。沈墨没有回来。德五爷的画眉，你卖给了一个洋人。
旁白：有一天，一个孩子来当一件棉袍。你看了一眼，说：“虫吃鼠咬，光板没毛。”
旁白：孩子哭着走了。你忽然想起王婆。你想不起来，她最后有没有赎回她的棉袍。
**【字幕】** 富贵是真的。只是，再没有人叫你“掌柜的”，只叫你“老爷”。

### 结局四 · 黑市枭雄

**【画面】** 夜。恒裕当后门。门外站着一排人，每个人都在等着敲“三长两短”。
旁白：天津卫的黑货，十件有八件，要过你的手。

旁白：你拿着那三页账，没有人敢动你。你成了胡二爷想成为的那个人。
旁白：有一天夜里，后门响了。三长两短。你问：“几更了？”

### 结局五 · 义士

**【画面】** 上海，《字林西报》的一个版面；横滨，《清议报》的一页；天津城门，一张被雨打湿的黄纸。
旁白：师父的三页账，登在了洋人的报纸上，贴在了天津的城门上。
旁白：都统衙门查封了恒裕当一个月，罪名是“散布谣言”。
旁白：一个月后，封条揭下来那天，门口站满了人。王婆的孙子、刘铁头、张拉车、翠儿、慧明和尚……还有一个从保定回来的年轻教书先生（林生）。
- 若孙秀才来信 → 旁白：那年冬天，横滨寄来一封信。信里只有一句话：“君之义，天下知之矣。”
- 若沈墨存活 → 旁白：沈墨没有回京城。他在恒裕当的后屋，教小顺子认字。
旁白：四十七件东西，一件也没有找回来。可是从此以后，天津卫的人都知道——恒裕当的柜台后面，有一个不收不该收的东西的掌柜。
**【字幕】** 恒裕当，后来人称“义当”。

### 结局六 · 百年老号

**【画面】** 光绪二十七年春。恒裕当重新挂匾。小顺子站在梯子上，扶正了匾额。
旁白：你守住了铺子。也守住了规矩。
- 木匣：（物归原主）沈墨赎回了匣子。临走前，他在柜台上放下一张新的当票：“当：一个承诺。当期：天下太平。” / （交钱掌柜/德五爷保管）钱掌柜说：“我替你师父收着。”
- 寄存品：慧明的铜佛、小凤仙的头面、德五爷的鸟笼、林生的千里镜、钱掌柜的宋版……一件不少。
  - 小凤仙三年后回来了，在重开的茶园里唱了一出《玉堂春》。
  - 慧明重修了寺，来赎铜佛的那天，给恒裕当送了一块匾：“不欺”。
  - 德五爷的当票，一直没有人来赎。画眉每天早上都唱。
- 翠儿成了恒裕当的二掌柜。小顺子……成了“小朝奉”。
旁白：师父说，眼睛是本钱，人缘是利钱，规矩是本钱的本钱。
旁白：你这一辈子，没赚到多少钱。可是天津卫的人提起恒裕当，都说——
旁白：“那是家老字号。”
**【守成版差异】**（信誉 < 25）匾挂上了，客人却不多。旁白最后一句改为：“那家铺子，还开着。”
**【字幕】** 恒裕当，直至民国二十六年，仍在南市营业。
