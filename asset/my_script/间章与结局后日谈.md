# 第一部分 · 间章 · 己亥

## 1.1 位置与机制

**放在哪里**：第四章章末的【时间跳跃 · 字幕】之后，第五章【章首演出 · 一年半】之前。第五章章首的旁白（“光绪二十五年，天津卫过了一年太平日子……”）保留，用作间章收尾时的字幕，改为**依间章结果动态替换**（见 1.8 节）。

**怎么玩**：
- 间章共 **五幕**。每幕是一个“开门日”（辰时开门、酉时打烊），每幕 3～5 位剧情客人，另有少量随机客人。
- 幕与幕之间是 **【月结】**：这几个月的太平生意（活当利息、死当转卖、伙计工钱、铺捐）自动结算，不逐日经营。
- **不交旬息**：年关大账已结（或已封铺）。只有“余债”和“冤枉银”两种钱庄往来，见幕一。
- 物价沿用第四章。太平年景，随机客人均利按第四章的 **×0.8** 计（东西不值钱了，当的人少了）。
- 第五幕的 **【间章核心抉择】** 决定铺子怎么升级、人怎么安排，结果直接写进第五章开局（见 1.7、1.9 节）。

**【月结】净收入**（已扣伙计工钱每旬3两、铺捐、房屋修补；单位：两）

| 月结 | 时段 | 新手 | 普通 | 高手 | 说明 |
|---|---|---|---|---|---|
| 一 | 己亥正月下旬～二月 | +10 | +25 | +50 | 开春赎当多，利息回笼 |
| 二 | 三月～七月 | +15 | +30 | +70 | 太平生意最好的一段 |
| 三 | 七月～十月 | +10 | +25 | +55 | 秋旱，乡下来当农具的多 |
| 四 | 十月～腊月 | +5 | +20 | +45 | 山东流民又来，米价上涨 |
| 五 | 庚子正月～五月十四 | +0 | +10 | +40 | 大旱、揭帖、拳坛，生意清淡 |
| **合计** | | **+40** | **+110** | **+260** | 不含各幕剧情收支 |

- **流落路线**（第四章年关D·封铺）：月结收入 **×0.5**（只有小摊）。
- **钱庄典当生意**（第四章年关A·宽裕，幕一接下）：月结一～四各 **+10**。

> 设计目标：普通玩家间章净收入（约 110 + 剧情 ±30）大致够付**一项**核心升级；高手可以付两项；新手只够一项最便宜的，或者干脆不升级、靠人情。这样第五章普通档的结余仍在“刚好过关”的区间（见 1.9.3 平衡说明）。

## 2.1 形式：当簿

第五章各结局的【画面】【旁白】【字幕】播完之后，进入 **「后日谈 · 当簿」**：屏幕上摊开师父那本旧当簿，玩家一页一页往后翻。每位熟客占一页，格式仿当铺流水簿：

> **当簿 · 第 N 页**
> 当主：某某　　当物：某物　　当期：某日
> 批注：（下落，一到四句）

- 页序固定：王婆 → 翠儿 → 赵太太 → 孙秀才 → 德五爷 → 小凤仙 → 马三 → 钱掌柜 → 小顺子 → 沈墨 → 刘头 → 胡二爷 → 福公公 → 群像（一页多人）。

- 翻到最后一页是空白，留给第五章结局原有的【字幕】那一句。
- 不同结局当簿的样子不同：**劫灰**——页边焦黑，是你凭记忆重抄的；**破产**——不是当簿，是摊子上的估价簿；**卖主求荣**——新订的金漆簿子，很多页只有名字；**黑市枭雄**——两本，一明一暗；**义士**——簿子上贴着封条的残角；**百年老号**——师父那本原簿，后面续了新页。

## 2.3 结局一 · 庚子劫灰 · 后日谈

**【当簿 · 焦边】** 旁白：当簿烧了一半。后来这一本，是你在北门外的粥厂里，凭记忆一页一页重抄的。

**王婆**
- W1 → 火从隔壁烧过来的时候，是栓子把你从库房里拽出来的。那年冬天，王婆没熬过去。栓子在粥厂替你舀粥，舀到开春。
  批注：“棉袍，庚子六月十八焚。当主之孙栓子，不要赔。”
- W0 → 王婆来粥厂问过一回她的棉袍。你说烧了。她说：“烧了好，省得惦记。”
  批注：“焚。未赔。”

**翠儿**
- 伙计 / 二柜 → 火起时她抱出来一摞当簿，就是你后来照着重抄的那一摞。她在粥厂管女棚的账，一个钱不差。光绪二十八年，她嫁给了粥厂里一个识字的伙夫。出门那天，你按当铺规矩开了一张当票送她：“当物：素银簪一支。当期：一辈子。”
- 在赵家 → 随赵太太（见下）。
- 烟馆未赎 → 批注只有两个字：“不详。”

**赵太太**
- Z+ 且库存挪进了赵家地窖 → 铺子烧了，地窖里的东西还在。赵太太叫管家把一箱一箱当物抬到粥厂：“掌柜的，东西是你的，账也是你的。”你拿着残页一家一家去找当主，找到的不到一半。
  批注：“地窖存物，退还当主三十一家。余者无主，捐粥厂。”
- Z+ 无地窖 → 赵家也被抢了。赵太太卖了几件首饰，给粥厂捐了一口大锅。
- Z− → 赵家南下扬州。临走她托人带话：“那只金镯，我不要了。”

**孙秀才**
- 日本 → 横滨的信寄到恒裕当，邮差找不到铺子，一路问到粥厂。你在信纸背面回了一行字：“铺子烧了，账还在。”光绪二十八年他又来了一封，只有三个字：“君安否？”
- 捕 → 批注：“城陷日，府监门开。有人见一跛足书生南去。”
- 远 → 他再也没来过。

**德五爷**
- 太平 → 那张“太平之日”的当票，跟铺子一起烧了。画眉是你抱出来的。你把鸟笼挂在粥厂棚子底下，每天卯时，它唱“山喜鹊”。
- 劝 → 德五爷没去南门，跟你一起在粥厂舀粥。“爷这辈子没干过活，就从舀粥干起。”
- 去 → 批注：“南门守城旗兵，无一人回来报名。”

**小凤仙**
- 恩人 / 租界（寄存了头面）→ 点翠一碰就成了灰。三年后她回到天津，你把一只空锦盒还给她。她站在粥厂门口清唱了一段《玉堂春》，没有锣鼓。
- 南边 → 她那只戏箱，跟你的铺子一起烧了。

**马三**
- 批注：“海光寺。手里那匹绸缎，是隔壁布庄的。布庄也烧了。”

**钱掌柜**
- 寄存 → 宋版烧了。钱掌柜在废墟里站了一下午，最后弯腰捡起一块焦了的书角：“书烧了，眼睛还在。”他写了一封荐书，让你去琉璃厂一位老朋友那里做伙计。
  批注：“荐书一封，未用。你说你还得替人写当票。”
  - 若间章托他转过龙骨 → 附：“那年七月，京里那位王大人投了井。他认出来的字，后来有人接着认。”
- 去 → 南下，再没回天津。

**小顺子**
- 信任≥3 → 他跟着你去了粥厂，你写当票，他磨墨，替不识字的人念当票上的字。
- 信任<3 → 他去码头扛活，每隔几天来粥厂看你一回。
- 碑阴 / 最后一件事 → 见2.2。西关外的那块碑没烧。

**沈墨**
- 活，且木匣内容已托出（公之于世或物归原主）→ 他带着抄件和清单南下上海。批注照抄第五章结局原文：“那三页账，没有烧。”
- 活，木匣未托出 → 匣子和你师父的信一起烧成了灰。沈墨在灰堆前站了一夜，第二天回京，辞了差事。
- 死 → 批注：“当主已故。当物焚。当票半张，在我手里。”

**刘头**
- 留 → 他替你守门，被流弹擦伤了胳膊。都统衙门招华捕，他去了。每月初一往粥厂送五两，说是“还你师父的”。（有间章“还债”标记 → 送满三十五两那个月，他没再来，托人捎话：“还完了。”）
- 钱 → 他在杨柳青种了两亩地。
- 走 / 交 → 批注：“五十两，未还。”

**胡二爷**
- 按2.2判定。劫灰附笔：钱庄的账、K&Co.的账、恒裕当的账，三处都烧了。
  - 木匣未托出 → “他要找的那三页纸，最后谁也没找到。”
  - 木匣已托出 → “他要找的那三页纸，登在了洋人的报纸上。”

**福公公**
- 按2.2判定。劫灰附笔：恩济庄、吴甸，离天津都远。你再没听人提起过他。

## 2.6 结局四 · 黑市枭雄 · 后日谈

**【两本当簿】** 旁白：一本明账，摆在柜台上。一本暗账，锁在你师父当年的暗格里。

**王婆**

**翠儿**

**孙秀才**

**德五爷**

**钱掌柜**

**沈墨**

**刘头**
- 留 / 钱 → 光绪二十八年新办巡警，他进了南段巡警局，成了你在局子里的人。
- 走 / 交 → 死于西门外。

**福公公**

## 2.7 结局五 · 义士 · 后日谈

**【当簿 · 封条残角】** 旁白：这本当簿的封皮上，贴着半截都统衙门的封条。揭封那天，你没舍得撕。

**王婆**
- 第五章原文：揭封那天，门口站着王婆的孙子。
- W1 → 栓子后来进了恒裕当做学徒。
- W0 → 王婆也来了，站在人堆最后面。

**翠儿**
- 伙计 / 二柜 → 查封那一个月，她把所有该赎当的日子按天记下。揭封第二天，一家一家去通知：“恒裕当的当期，顺延一个月，不加利钱。”
- 在赵家 → 她跟着赵太太，在联名保状上按了手印。
- 烟馆未赎 → 不详。

**赵太太**
- Z+ → 都统衙门查封恒裕当时，是赵太太带头递的联名保状，城西三家大户都按了手印。地窖里的当物，揭封那天原样抬回来。
- Z− → 南下扬州。她在扬州读到了上海的报纸。

**孙秀才**
- 日本 → 第五章原文：那年冬天，横滨寄来一封信：“君之义，天下知之矣。”

- 远 → 无消息。

## 2.10 附 · 与既有设定可能冲突、需确认之处
