# 《典当春秋》随机客人对话库

> **用途**：填充各章剧情客人之间的空档——每日 8~12 位客人中的非剧情位、第二章第16~19天“寻常日”、第四章第22~23天“冬衣潮”、第五章围城减员日等。
> **配套**：职业图鉴见《游戏设计方案》5.1；物品从各章《客人与物品配置表》的“物品表”按“品类 + 来路 + 首次出现(天)”抽取；收益口径沿用各章收支模拟的“随机客人均利”。
> **标记**（沿用各章脚本）：`【选项】` / `【盘问】` / `【讨价】` 玩家操作；`→` 结果；`{数值}` 系统效果；`` `[破绽]` `` 可被玩家发现的线索。
> **本库新增标记**：`〈变量〉` 由程序填入（名字、物品、地名、洋行等）；`「章变·X」` 在 X 章/段替换对应台词；`实：` / `谎：` 说谎判定后二选一的应答；`[破绽·XX-a]` 职业破绽池中可随机插入的条目。
> **铁律**：随机客人**不得说出任何主线新真相**（沈墨身份、木匣内容、三页账、广储司、胡二爷失手推死师父、补页伪造、刘头受贿等），只能复述玩家**已解锁**的街谈巷议。详见第十九节 R7。

### CF-01 「天暖当棉袄」（老实型）
**适用**：一、二　**物品**：衣物·清白　**说谎率**：0.1（谎点：赎期）　**耐心**：3　**偏好**：活当

车夫：（把车把往门外一靠，抱着棉袄进来）掌柜的，介棉袄您给瞧瞧。开春了，跑起来一身汗，穿不住。
车夫：当俩钱，交车份儿。秋凉了我再来赎。

【盘问】（耐心3）
1. “车是你自己的？”→ 车夫：“自己的？我要有辆车还当棉袄？车厂赁的，份儿钱一天不交，第二天就不赁给你。”
2. “秋凉了是几时？”→ 实：“八月节前准来。”／谎：“……那、那得看活儿。”`{谎：此单死当概率+20%}`
3. “家里几口人？”→ 车夫：“老娘、媳妇、俩小子。都指着我这两条腿。”

【讨价】
- 低档 → 车夫：“嘿！光板没毛？介是去年新絮的棉花！……得，您是掌柜，您说了算。”`{耐心-1，仍成交}`
- 中档 → 车夫：“行，比我想的还多俩子儿。”
- 高档 → 车夫：（一愣，咧嘴）“掌柜的您倍儿局气！回头您坐车，我不要钱！”`{本旬车夫类客人耐心+1}`

成交：车夫：（把当票揣进贴身褂子，拍了两下）丢了介张纸，棉袄就不是我的了。
不成交：车夫：得嘞，我上对门同和当问问去。

「章变·三前」开场改：“立秋了，夜里凉。可份儿钱先得交上——棉袄先放您这儿，入冬前准赎。”
「章变·四前/四后」不当棉袄，改当号坎和车铃：车夫：“棉袄不能当，当了冻死。介号坎、车铃铛，您看值几个？……号坎当了，车厂不让出车；可米都六两一石了。”`{物品改为杂项}`

### QR-01 「钱粮没关下来」
**适用**：一、二、三前、三后、四前　**物品**：鼻烟壶（料器/瓷胎）·清白　**说谎率**：0.4（谎点：“宫里赏的”）　**耐心**：3　**偏好**：活当

### R2 每日生成流程

1. **随机位数** = 当日客流（8~12）− 当日剧情客人数；再乘街面事件修正（如第一章第6天米价涨：客流+20%；第五章围城：每日递减）。
2. **抽职业**：按第一节权重表取当前段的权重，再乘事件修正：
   - “急当比例+10%”（第二章布庄伙计失业、米价小涨）→ 车夫、流民、小脚太太、烟鬼权重 ×1.2；
   - “当冬衣换米+30%”（第四章米价六两）→ 衣物类套与流民 ×1.5，CF-01 自动切换为「章变·四前」；
   - 第四章第22~23天冬衣潮 → 随机位数 ×1.5，物品品类“衣物”优先；
   - 第五章章首选“门口挂扶清灭洋旗” → 洋行买办、洋教士权重 ×0.5。
3. **抽套**：在职业内过滤“适用段”“互斥”，再按**冷却**：同一套一章内≤2次，同一旬内≤1次；同一职业同一天≤2位。
4. **抽物品**：按套内“物品规则”，从本章物品表中取“品类匹配 且 首次出现(天) ≤ 今日”的条目；来路、真伪按权重。无匹配时使用“兜底物品”，数值按本章物品表价值的 20/50/80 分位生成低/中/高价位，并在配置表补“R-”前缀的随机物品行（见第二十节）。
5. **说谎判定**：`rand < 说谎率` → 走所有盘问的“谎”应答；否则走“实”。**物品为假货或赃物时强制按“谎”处理**（套名注明“老实型”的除外，此时假货为客人也被骗）。
6. **破绽插入**：每位客人 1~3 个破绽 = 套内固定破绽 + 0~2 个职业池破绽。约束：
   - 工具未解锁的不插入（放大镜第二章、图谱第三章、打听第四章；戥子第一章第3天）；
   - **破绽必须指向物品或客人的真实属性**：不得给清白货插赃物破绽；“误报”只由小顺子系统（附A的 10% 误报）产生；
   - 同一天内同一条池破绽不重复。
7. **填变量**：〈名字〉取称呼池；〈地名〉〈洋行〉〈营头〉〈佐领名〉〈班名〉〈堂号〉等取各职业卡对应池；〈洋行〉永不取 K&Co.。
8. **时局闲话**：按第十八节以 30% 概率插入。
9. **讨价三档**：设物品表“客人开价”为期望价 E，“建议当价/建议绝卖价”×0.9 为底线 F（随耐心浮动：耐心每少1，F 下移 5%）。玩家报价 P：
   - P < F → **低档**；
   - F ≤ P < E → **中档**；
   - P ≥ E → **高档**。
   - 行话命中（职业卡“对口行话”）：F 再下移 10%，且低档不扣耐心；洋教士不吃行话（不加成、不扣分）；旗人对“当”字扣耐心 2。
   - 票据（期票、船契、房契）：E = 面值 × 0.5，F = 面值 × 0.2。
   - **说谎者的高档反应**：耐心-1，并以 20% 改口加价或起疑离开（各套“高档”台词已体现）。
10. **耐心**：初值 = 套耐心；每问一句 −1；低档报价 −1；触犯忌讳 −2。耐心归零 → 播放“不成交”并离开。例外：套内注明“急于脱手”的，归零时接受玩家最后一次报价。
11. **声望结算（重要）**：见 R11。
12. **活当回访**：见 R12。
