# 《典当春秋》第一章 · 清明 —— 客人对话脚本

> 对应配置表：客人ID（C**）、物品ID（I**）。
> 标记说明：`【选项】` 玩家选择；`→` 结果；`{数值}` 系统效果；`[破绽]` 可被玩家发现的线索。
> 主角称呼：客人叫“掌柜的”或“朝奉”，主角自称“小号”“本号”。

---

## 序章 · 除夕之后（开场演出）

**【黑屏 · 更夫梆子声】**

旁白：光绪二十四年，正月。天津卫，南市。
旁白：恒裕当的陈掌柜死在库房里，手里攥着半截账页。
旁白：他的徒弟——你，是这铺子里唯一还没走的人。

**【白天 · 恒裕当柜台后】**

胡二爷（C16）：（敲柜台，玉烟嘴叼着）哟，小朝奉，节哀。
胡二爷：节哀归节哀，账得算。你师父拿铺子押了我们义和钱庄三百两。
胡二爷：（拍拍蓝布包，没打开）这是头一张。别的账……等你站稳了，再慢慢算。
`[破绽]` 他说“头一张”——第二章的补页伏笔。
胡二爷：两条路：签了这张借据，铺子归你，每旬交息；不签，今儿就封门。

【选项】
1. “我签。”
2. “我师父从没提过这笔账。”
3. （沉默，看借据）

- 选1 → 进入签字。
- 选2 → 胡二爷：“死人提不提，借据上有他的手印。”→ 进入签字。`{江湖名声+1}`
- 选3 → 玩家可放大借据，发现 `[破绽]` 借据日期在师父死前三天。→ 记入《疑点簿》，进入签字。

胡二爷：（收起借据）每旬三十两。交不上……这条街上，没人能护着你。

**【教学提示】** 按住印章盖在借据上 = 确认。

## 第1天 · 开张

### C01 王婆 · 粗布棉袍（教学：活当、当票）

王婆：（踮脚够柜台）掌柜的……掌柜的行行好，这袍子，当几个钱？
王婆：老头子病了，抓药要钱。开春了，袍子我先不穿。

**【教学】** 拖动物品到鉴定台。眼力：袖口磨破、有补丁。

【选项 · 报价】
1. 用行话：“虫吃鼠咬，光板没毛——当您一钱五。”
2. 照实说：“旧袍子，给您二钱。”
3. 多给：“三钱，拿去抓药吧。”

- 选1 → 王婆叹气：“行……行。”`{当价最低，信誉不变}`
- 选2 → 王婆：“谢掌柜的。”`{正常}`
- 选3 → 王婆眼眶一红：“好人，好人有好报。”`{信誉+2，利润为负}` → 解锁王婆后续：第六章她孙子会来报信。

**【教学】** 写当票：物品、当价、当期三十天、月息三分。盖章，撕下半联交客人。

王婆：（攥着当票）三十天，一准来赎。

### C02 油头少年 · “金镯子”（教学：试金石、假货）

油头少年：（啪地拍在柜台上）足赤真金！我娘陪嫁的，五两银子，少一个子儿不当！
油头少年：快点快点，我还有事。

`[破绽]` 他反复强调“足赤”；镯子拿在手里偏轻。

**【教学】** 取出试金石，在石面划一道，与对金牌比色。
→ 划痕发黄带红：**铜胎鎏金**。

【选项】
1. 当面拆穿：“铜的，镀了层金。”
2. 照“淡金”压价，低价收下。
3. 不识破，按真金收。

- 选1 → 少年脸一红，抢回镯子：“你、你等着！”`{信誉+1}` 后续：第7天他带地痞马三来闹（C07的伏笔）。
- 选2 → 以一钱收下。`{亏损极小，江湖名声+1}`，可在第7天转卖给不识货的人。
- 选3 → `{按开价40%损失3.2两}` 打烊时提示：“这一行，眼睛就是本钱。”

### C03 蒙面人 · 上锁樟木匣（主线钩子）

**【音效：铺子门帘被风掀起】**

蒙面人：（斗笠压低，不抬头）当。
你：当什么？
蒙面人：（把木匣推上柜台）三十日。必来赎。
你：本号规矩，要验货。
蒙面人：（手按在匣子上，手背一道刀疤）不验。

`[破绽]` 他按匣子的左手中指有墨茧——读书人的手，不是江湖人。
`[破绽]` 匣底刻一个小小的“内”字。

【选项】
1. “不验货，本号不收。”
2. “当价二十两，不问来路。”
3. “……您是读书人吧？”

- 选1 → 蒙面人沉默片刻，放下二十两银票：“这是押金，不是当价。”→ 强制收下。`{现银+0，库存+木匣}`
- 选2 → 收下，付他二十两……你付不起。蒙面人：“那就当一两。匣子比你的命值钱。”`{现银-1}`
- 选3 → 蒙面人第一次抬头，盯着你：“……好眼力。三十日。”`{解锁主线线索“读书人”}`

**【系统】** 木匣进入库房“不可开启、不可转卖”栏。当期：30天。

### C04 刘铁头 · 铜脸盆、锡酒壶（普通交易，放松节奏）

刘铁头：掌柜的，收破铜烂锡不？
刘铁头：我是铜匠，这俩修不好了，换俩钱喝酒。

- 绝卖，按“烂铜”“烂锡”压价，他不太还价。
- 若玩家第1天对王婆多给钱 → 刘铁头：“听说你给王婆多给了？跟你师父一个脾气。”`{补一句人物塑造}`

## 第2天

### C05 翠儿 · 素银簪（人情链：翠儿线）

翠儿：（贴着门框，左右看）掌、掌柜的……这簪子能当吗？
你：哪儿来的？
翠儿：娘、娘给的。

`[破绽]` 簪身内侧刻着一个“赵”字——翠儿姓李。

【盘问选项（最多问两句，耐心3）】
1. “你娘叫什么？”→ 翠儿：“……李、李氏。”（耐心-1）
2. “你在哪家做事？”→ 翠儿：“城西……赵家。”（耐心-1，破绽对上）
3. “这上面刻的是谁家姓？”→ 翠儿当场哭了。（耐心归零，直接进入抉择）

【抉择】
1. 收下，不多问。
2. 收下，但劝她：“三十天内赎回去，别让主家发现。”
3. 不收：“偷主家东西是要挨板子的。”
4. 记下她的话，报给赵家。

- 选1 → `{江湖名声+1}` 第6天赵家管家上门找簪子（赃物盘问）。
- 选2 → `{信誉+1}` 第6天翠儿来赎回，感谢你。→ 第3天出现的赵太太（C08）正是翠儿的主母，伏笔衔接。
- 选3 → 翠儿跑掉。`{无交易}` 第6天她又来，这次当的是自己的耳环。
- 选4 → `{官府/大户好感+1，江湖名声-2}` 翠儿被赶出赵家，后续第三章在烟馆门口看到她。

### C06 孙秀才 · 石印本《三国》、端砚（人情链：维新线伏笔）

孙秀才：（作揖）掌柜的，小生孙某。这部书，这方砚，暂押贵号。
孙秀才：“君子固穷”嘛，待来年秋闱……呵，大概也没有秋闱了。
你：秀才这话怎么说？
孙秀才：（压低声音）京里有人要变法。科举怕是要改了。

**【对话彩蛋】** 他说话爱引典故，若玩家选“您这是‘孔乙己’啊”的选项 → 被禁用（时代未到），替换为：“秀才说话，像唱戏。”→ 孙秀才大笑。`{好感+1}`

- 书按“残书破本”压价。端砚他不让压：“端溪石眼，你识货就知道。”
- 若识出“石眼清晰” → 给足价，`{好感+2}`，解锁第9天他的回访更早出现信任台词。

## 第3天

### C07 马三 · 灌铅小元宝（教学：戥子）

**【系统】** 解锁新工具：戥子。

马三：（搭着柜台，笑）小朝奉，头一回见。五两的元宝，当四两，够意思吧？
马三：你师父在的时候，咱俩可熟。

`[破绽]` 元宝表面过亮；掂着手感偏沉；他不肯让你上秤：“称什么称，你信不过我？”

【选项】
1. “本号规矩，银子必过戥子。”（强制称重）
2. “看在师父面子上，收了。”
3. “马爷，这银子里头怕是有货吧？”

- 选1 → 称重超标，剖开见铅。马三翻脸：“行，小崽子，你等着。”`{信誉+1}` 第7天马三报复事件。
- 选2 → `{损失约1.6两}`
- 选3 → 马三眯眼：“……会说话。行，这锭我拿回去。我那还有别的货，过两天来。”`{江湖名声+2，解锁马三“黑货渠道”}`

> 若第1天拆穿过油头少年 → 马三多一句：“我表弟说你眼毒，果然。”

### C08 赵太太 · 绸面夹袄（第3天）、嫁妆金镯（第5天）（人情链：嫁妆金镯线）

赵太太：（手绢遮着脸）快些办，别让人看见。
赵太太：这夹袄先当着……家里周转，周转。

- 第3天：普通活当，教学“当期内可赎”。
- 若第2天翠儿线选2 → 赵太太：“我家丫头翠儿说你这儿厚道。”

**第5天回访：**

赵太太：（这次没遮脸，眼睛是肿的）这对镯子……是我的陪嫁。
赵太太：我家老爷在外头赌钱，欠了钱庄的。我得替他还。
你：哪家钱庄？
赵太太：……义和。

`{主线线索：义和钱庄也放债给赵家}`

【选项】
1. 按规矩当价（三成到五成）。
2. 多给一些，当期延到六十天。
3. “太太，这镯子您留着，钱庄那边……我帮您打听打听。”

- 选1 → 正常。第10天后她若未赎 → 死当，玩家获利，`{赵太太后续敌意}`
- 选2 → `{现银压力大，信誉+2}` 第四章赵太太掌家，介绍大户生意给你。
- 选3 → 不交易，`{解锁“打听”功能提前，主线：钱庄的账}`

## 第4天

### C09 德五爷 · 玉扳指、朝珠（人情链：德五爷线；教学：行话）

德五爷：（提鸟笼，进门先看笼子不看你）小掌柜。爷今儿个手头不便，来“借”点儿。
**【系统提示】** 旗人忌讳“当”字。说“当”会触怒他。

【选项】
1. “五爷要当什么？”
2. “五爷要借什么，押什么？”
3. “五爷，您这扳指真不错。”

- 选1 → 德五爷鸟笼一顿：“当？爷是来当东西的人吗？！”`{耐心-2}`
- 选2 → 德五爷满意：“懂规矩。”`{耐心+1}`
- 选3 → 德五爷：“那是！乾隆爷赏我太爷爷的。”（`[破绽]` 是否真为赏赐可验）

**【鉴定】** 眼力：青白玉，内壁血沁 → 真品。
**【行话教学】** 玉器压价叫“石头”。

你：（行话）五爷，这块石头……
德五爷：石头？！你管这叫石头？
→ 玩家选择坚持 / 改口：
- 坚持 → `{当价低，德五爷耐心-1，但不会走——他急用钱}`
- 改口 → `{当价高，德五爷好感+1}`

**收尾台词（无论选择）：**
德五爷：（走到门口回头）小掌柜，八旗的铁杆庄稼，到我这辈儿，就剩这只鸟了。

### C10 鹞子李 · 染色石扳指、仿乾隆碗（骗子）

鹞子李：（拱手，礼数周全）在下正黄旗后裔，祖上传的戒指，请掌柜的过目。

`[破绽1]` 旗人不会把扳指叫“戒指”。
`[破绽2]` 若德五爷当天来过，玩家可选对比台词：“刚才五爷说，这叫扳指。”

【选项】
1. 鉴定后拆穿：“色是染的。”
2. “正黄旗？您是哪个佐领下的？”（盘问）
3. 收下。

- 选2 → 鹞子李支吾：“这……佐领……”→ 自动暴露。`{信誉+1，解锁成就“旗下规矩”}`
- 选3 → `{损失约3.7两}`
- 第6天他会带仿乾隆碗再来，换个身份（自称“内务府笔帖式”）。若玩家第4天识破过 → 新选项“又是你？”直接赶走。

### C11 张拉车 · 东家的怀表（赃物；触发巡警）

张拉车：（满头汗）掌柜的，这表……东家赏的。当六两就行，急用！

`[破绽]` 表盖内刻洋文名字“J. Morrison”；张拉车不识字，问他刻的啥，他说“吉祥话”。

【选项】
1. “这表不是你的吧？”
2. 收，不问。
3. 收，但当价压到三两：“来路不明的价。”

- 选1 → 张拉车跪下：“东家欠了我仨月车钱！我、我就拿个表……”
  - 再选：【收下】`{江湖+1}` /【劝他还回去】`{信誉+1，无交易}` /【扣下表，报官】`{官府+2，江湖-2}`
- 选2/3 → 当天下午巡警刘头（C17）上门：

**巡警刘头（C17）：**
刘头：（警棍敲柜台）英租界莫理循先生丢了一块金表。小掌柜，见过没有？

【选项】
1. “没见过。”（若表在库房：盘查判定，被搜到 → 罚银10两）
2. 交出表，供出张拉车。`{官府+2，江湖-2}`
3. （塞银子）“刘头辛苦，喝杯茶。”`{现银-2，刘头不搜；记“好说话”标签，后续勒索频率+}`

## 第5天

### C12 小凤仙 · 点翠头面（人情链：戏班赌债线）

小凤仙：（胭脂没卸，进门一个亮相）掌柜的！今儿个唱完《玉堂春》，奴家急着赶场。
小凤仙：这副头面，点翠的，班主不知道，您可别声张。

- 鉴定：翠羽有脱落 → 真品，有瑕。
- 盘问“为何急用钱” → 她一下变脸，冷冷地：“问那么多做什么？”`{耐心-2}` → 再问 → 她哭着说出班主欠了赌债，要卖她。

【选项】
1. 正常活当。
2. 多给，不问。
3. “头面我收，人……你自己想清楚。”

- 第二章伏笔：班主来找头面；玩家可选择帮她赎身（花大钱）或不管。

## 第6天 · 真假人参

**【街面事件】** 早上开门，街口粮店挂出新牌子：米价每石涨三钱。
旁白：米贵了，来当东西的人就多。`{今日客流+20%}`

### C13 胡郎中 · 老山参 + 萝卜雕假参（教学：同类对比、拆包验货）

胡郎中：（药箱往柜台上一放，山羊胡一翘）掌柜的，好东西！长白山老山参，一对儿！
胡郎中：一支是山里挖的，一支是它“兄弟”，长一块儿的。二十五两一对，拆开不卖。
你：拆开看看。
胡郎中：哎——参有灵性，见了生人气就跑味儿。您隔着红布瞧瞧就成。

`[破绽1]` 两支参品相几乎一模一样——野山参“一参一个样”，长得太像反倒可疑。
`[破绽2]` 他坚持“一对一起卖”，不让分开验。
`[破绽3]` 掀开红布细看：一支芦头长、须上带“珍珠点”；另一支断须处没有纹，指甲一掐，渗出水来。

**【教学】** 同类物品可以并排放上鉴定台对比。“哪里不一样”比“像不像”更容易看出来。

【选项】
1. “拆开，我只要一支。”
2. “这支是萝卜刻的吧？”（须先发现破绽3）
3. 不验，二十五两收下一对。
4. “胡先生，咱们说句行话——烂参，一对给您八两。”

- 选1 → 胡郎中：“拆开不卖！”→ 再选：
  - 坚持 → 他收起药箱：“不识货。”`{无交易，信誉+1}` 第8天他换了一支假参去对门的“同和当”，玩家在街上听人议论“同和当吃了个哑巴亏”。
  - 让步 → 进入选3。
- 选2 → 胡郎中干笑：“……掌柜的好眼力。那支是样子货，给您配个对儿，图个吉利。”
  - 【只买真参，十八两】→ `{正常利润，信誉+1}`
  - 【两支都要，但按一支真参的价】→ 胡郎中咬牙答应。`{利润最高，江湖名声+1}` 假参可在第7天转手给不识货的烟鬼周（C14）——玩家自己决定要不要这么做。
- 选3 → `{按开价40%算，亏损约7.9两}` 打烊提示：“野山参，一参一个样。”
- 选4 → 胡郎中：“八两？您这是要我的命！”→ 进入讨价还价，三轮内能谈到十二两左右。若玩家已经发现假参，额外出现选项“一支烂参，一根萝卜，八两不少了”→ 胡郎中当场成交。`{江湖名声+1}`

## 附A：学徒小顺子（新手辅助系统）

> **触发条件：** 连续误收 2 件假货（系统判定，玩家无感知）。高手玩家整章不会触发。

### 提醒台词（鉴定阶段，按物品类型触发）

> 规则：仅对“假货”或“来路有问题”的物品触发；约 **80%** 正确提醒，**10%** 误报（对真货起疑），10% 不吭声——保留玩家判断空间。
> 数值衔接：新手采纳提醒的概率约 55%，有效漏看率 = 60% ×（1 − 80% × 55%）≈ **34%**，与收支模拟中的 35% 一致。若实测采纳率偏低，可把揽客收益或第二旬息银作为调节阀。

| 物品类型 | 提醒台词 | 指向的破绽 |
|---|---|---|
| 金银首饰 | “师哥，这镯子……拿着是不是有点轻？” | 分量（鎏金铜） |
| 银锭 | “师父说，银子不过戥子，就是没过手。” | 称重（灌铅） |
| 玉器 | “这颜色……怎么跟浮在上面似的？” | 染色 |
| 瓷器 | “这碗也太亮了，晃眼。老碗没这么亮吧？” | 贼光 |
| 字画 | “这章盖得真整齐……整齐得跟新刻的一样。” | 印章 |
| 药材 | “两根参长得跟双胞胎似的，山里的东西能这么像？” | 同类对比 |
| 赃物 | “师哥，这表上刻的是洋字，他识字吗？” | 来路 |
| 禁物 | （拉你袖子）“这味儿……师哥，巡警鼻子可灵。” | 盘查风险 |
| **误报（真货）** | “这扳指里头怎么有红道道？是不是坏了？” | 实为血沁，是真品特征 |

**玩家听从后识破 →** 小顺子：（得意）“我就说吧！”`{小顺子好感+1}`
**玩家不听、事后证明收错 →** 打烊时小顺子小声嘀咕：“……我说了的。”
**误报被玩家纠正 →** 小顺子：“血沁？……哦！师哥懂得真多。”`{小顺子好感+1，下次同类误报率降低}`
