## 一、统一换算原则

### 1.1 “真实价值”的定义
本作的 **真实价值 = 光绪二十四至二十六年（1898–1900）天津市面上，懂行的买卖双方之间的公平成交价**（以库平银两计，1 两约合制钱 1300–1400 文）。下面三种都**不算**：
- 收藏价（藏家出高价求精品）；
- 现代拍卖价；
- 贡品、御用品的“身份价”。

对方表覆盖 1840–1912 年全中国，不少区间按收藏口径估算。拿来对照之前，先按 1.2 换算成本作口径。

### 1.2 对方区间的换算规则
| 情形 | 换算方法 | 适用条目 |
|---|---|---|
| 收藏 / 名品 / 贡品口径 | 区间 ×0.3，折回市面成交价（行家收货价约为藏家价的三成，系数【待核】） | 文玩表稀有及以上（A09–A18）；消耗品 C09 野山参的上限（备注“内务府垄断”，上限是贡参价） |
| 现代拍卖价 | 不采用，只用对方的“设计估算”下限再按上一行换算 | A17 乾隆珐琅彩瓶（备注引用现代拍卖） |
| 数量 / 单位不同 | 按件数折算（一箱、十匹、合订本等） | 洋布、洋火、子弹、鸦片、报刊 |
| 完整度 / 器型 / 厚薄不同 | 半挂朝珠 ×0.5；碗、盘相对瓶 ×0.5；棉衣相对单衣 ×2（系数【待核】） | 朝珠、瓷器、号衣与棉军袄 |
| 跨档（同类但不同等级，比如无款对名款、当朝官窑对前朝官窑） | 不直接比较，只检查本作没有越过对方高档的上限 | 青白玉扳指、无款内画壶、光绪黄签碗 |
| 对方写“非卖品 / 赏赐 / 剧情物” | 只核对设定是否一致，不比价格 | 东珠朝珠、花翎、黄马褂 |

### 1.3 判定与取值
1. **一致**：本作原值落在换算后的区间内，或偏离近端不超过 1.5 倍。保留原值。
2. **偏离、保留**：偏离 1.5–2.5 倍。保留原值，标“待核”。
3. **明显不合理**：偏离超过 2.5 倍。按下面的顺序取新值：
   - 有史料来源的一方为准（对方表中“有来源”的条目，或本作考据报告、本轮查到的外部资料）；
   - 双方都没有来源时**取中位**，用对数中位：**新值 = √(本作原值 × 对方换算区间的几何中点)**，四舍五入到 0.1 两，标“待核”。价格按倍数差异，用几何中位不会被大区间的上限拉偏。
4. **客人开价**：按原来的“开价 / 真实价值”比例同步调整。
5. **假货联动**：假货的真实价值不变。如果它冒充的真品改了价，假货的客人开价按同一倍率调整，这样“同类对比”的教学张力不变。这一项超出了“只改被修正物品”的字面要求，属于联动改动，单独列在 3.2 节。

### 1.4 来源可靠度标记
- **有来源**：附可查链接或对方表标“有来源”；
- **旁证**：来源存在，但年代、品类和本作物品不完全一致；
- **待核**：双方都是设计估算。
