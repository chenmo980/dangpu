# 《典当春秋》随机事件池与动态市场

> 配套数据表：`artifacts/随机事件与市场配置表.xlsx`（事件池、抽取参数、市场系数、囤还是卖，四张表全部由公式驱动，蓝字为可调参数）。
> 本文只设计**随机层**：固定剧情事件（主线节点、人情链、史实日期上的事件、结账日）一律不进随机池。
> 时代用语按《历史考据核查报告》处理：1902 年前天津没有县衙快班捕快，查赃一律写“县衙捕快/差役”；拳会在第四章只以“传言”出现，第五章才进城设坛。

---

## 一、设计目标

1. **每天开门都有一点不确定**：同一章重玩，遇到的街面风波、物价起落不一样。
2. **随机事件服务于“当铺经营”这件事**：它改的是客流、物价、盘查和现银，逼玩家在“收不收、囤不囤、交不交钱”上做决定，而不是单纯掉血。
3. **越往后越凶，但不抢主线的戏**：负面事件的权重逐章加大（第一章 ×1.0 → 第五章 ×1.6），金额跟着各章物价放大；固定剧情日不抽事件。
4. **有本事的人能从随机里赚钱**：正面事件（洋行收古玩、鬼市、买办大宗收货等）要玩家主动抓，抓得住的是高手。

---

## 二、抽取规则

| 规则 | 内容 |
|---|---|
| 每日判定 | 每天开门前按“每日事件概率”（寻常档 30%）判定今天有没有随机事件 |
| 候选池 | 本章适用 + 前置条件满足 + 不与进行中的事件互斥 |
| 权重 | 按事件权重抽一个；负面事件权重 × 本章“负面权重倍率”（1.0 / 1.1 / 1.25 / 1.4 / 1.6） |
| 每日上限 | 每天最多 1 个随机事件；连锁事件不占名额 |
| 连锁 | 事件结束后 2~5 天内，以 50% 概率追加它的“连锁事件”；同一条连锁链一章最多触发 2 次 |
| 持续 | 持续型事件（如米价上涨 5 天）期间同一事件不会再抽到 |
| 禁抽日 | 主线节点日、旬末/节令结账日、史实日期（明定国是、政变、六君子、大沽、宣战、城陷等）当天不抽 |
| 金额 | 表中“基础两”按第一章物价；实际金额 = 基础两 × 本章金额规模（0.5 / 4 / 8 / 14 / 6） |

**折算损益**（用于数值期望，不是游戏内显示）：
折算 = 直接现银 + 客流% × 日均毛利基 3 两 × 天数 × 0.5 − 盘查率% × 4 两 × 天数 × 0.3。
品类价格效果不计入折算，而是进入“动态市场”，由玩家的囤卖决定来兑现。

### 5.2 叠加规则
- **实际系数 = 章节基准 × 所有进行中事件的系数**（连乘），上下限 0.3~2.5。
- **每日随机波动**：±3% / ±5% / ±6% / ±8% / ±15%（第一到第五章），让同一件东西每天的报价略有不同。
- 事件结束次日恢复章节基准。玩家可在“当行公所议价”（R05）后提前一天得知下一个事件。

### 5.3 “囤还是卖”决策示例

表里四个示例全部由公式计算，概率按事件池的权重和每日事件概率推出。

1. **第四章 · 寒潮前囤皮袄**：10 件羊皮袄每件 5.25 两收进。现在卖每件 10.01 两；等十天，寒潮来的概率约 11%、对过甩卖的概率约 12%，期望单价 10.17 两，扣掉资金占用后**囤比卖多赚约 1.1 两**。差得不多，所以“囤”只是小赌；如果玩家听到当行公所的消息、知道寒潮要来，囤就稳赚。
2. **第五章 · 洋货是留是甩**：60 两真值的洋货现在甩给洋行能拿 24 两；再拖七天，拳坛传言和教案风声随时会把价格再砍两三成，期望只剩约 22 两，**应该马上甩**。乱世里洋货越拖越不值钱，还可能被当“二毛子货”烧掉（剧情另计）。
3. **第二章 · 瓷器等不等洋行**：40 两的瓷器现在卖 44 两；等十天，洋行来收古玩的概率约 8%，期望 44.3 两，**等一等略划算**，但差额很小。这是一个“看你耐不耐得住”的选择。
4. **第四章 · 囤米还是平价卖米**：20 石存米，囤到米价上涨再卖期望约 86 两，平价卖给流民 60 两，**差价约 26 两**。这个选择同时挂着剧情节点：囤米居奇（信誉−2、江湖+1、黑市标记+1），平价卖米（信誉+3、义举+1）。玩家等于在用银子换名声。

## 六、程序实现要点

- **数据**：事件表直接导出 JSON。前置条件写成表达式字符串，如 `信誉>=8`、`flag:夜当已解锁`、`event:S02 或 event:T01`、`现银>应付*1.2`。
- **随机种子**：事件抽取使用本局种子派生的子种子 `seed_event = hash(局种子, 章, 天)`，详见《难度曲线与档位》的“重玩随机化”一节。
- **台词**：每个事件给出一句演出台词，实际可接入《随机客人对话库》里的“时局闲话池”，按事件 ID 抽对应闲话。
- **小顺子联动**：雇了小顺子之后，负面事件开始前一天他会多嘴一句预告（例如“师哥，西门外新开了个宝局”），这是新手的“预警”机制。
