# 《典当春秋》游戏设计方案
### 以 *Probably Stolen* 为蓝本的晚清中国当铺题材改编

---

## 0. 改编总纲：一一对应，再往外延伸

原版核心体验：前拾荒者借钱开店 → 在空间站底层收货卖货 → 鉴别假货、躲避安保、识破“带流氓AI的客人” → 每7天涨一次房租 → 最终把店买下来。

我们保留**骨架**，替换**血肉**，再加上中国当铺**独有的制度**作为新增玩法。

| 原版要素 | 晚清改编 | 新增延展 |
|---|---|---|
| 空间站底层 | 光绪二十四年（1898）·天津卫 城南（老城与紫竹林租界之间） | 租界与华界交界，洋货土货混杂 |
| 前拾荒者主角 | 落魄的当铺学徒“小朝奉”，师父暴毙，铺子将被收走 | 师父死因成为主线悬念 |
| 贷款开店 | 向“义和钱庄”借印子钱接手铺面 | 利滚利，按旬（10天）计 |
| 每7天涨房租 | 每“一旬”交一次息银，金额阶梯上涨 | 节令（端午/中秋/年关）为大结账日 |
| 鉴别假货 | 鉴别赝品古玩、灌铅银锭、仿洋表 | 实体鉴定小游戏（见3.2） |
| 安保盘查 | 县衙快班 / 衙役查赃 | 可行贿、可报官、可被敲诈 |
| 带流氓AI的客人 | 怀揣“密物”的客人：维新党、乱党、洋行奸细 | 与时代大事件挂钩（戊戌变法、义和团） |
| 按品类卖给买家 | 收进后转卖给“古董商、洋行、旗人、戏班”等 | 加入“当”与“赎”的双向循环 |
| 声望 | “字号信誉” + “江湖名声”双轨 | 决定结局与客群 |

> **关键差异化：原版只有“买和卖”，我们有“当、赎、死当、拍卖”。** 这是中国当铺最本质的制度，也是本作区别于原版的核心机制。

## 1. 世界观与开场

### 1.1 背景
光绪戊戌年春，天津。洋行林立、旗人没落、流民涌入。当铺“恒裕当”开在南市，门脸不大，柜台比人还高（真实当铺规矩，柜台高以示威势，顾客仰视）。

### 1.2 开场（对标原版的新手流程）
1. **黑屏旁白**：师父陈掌柜于除夕夜被发现死在库房，账本缺了三页。
2. **钱庄上门**：义和钱庄的胡二爷递来借据——铺子押给了钱庄，你要么接手还债，要么滚蛋。
3. **签当契**（教学：签字=确认操作）：接下首期借款 300 两白银，第一旬息银 30 两。
4. **第一位客人（教学关）**：老妪典当一件棉袍。
   - 教你看成色、写当票、报价、用行话。
5. **第二位客人（教学关）**：一个油头少年拿来“金镯子”——实为铜胎鎏金。
   - 教你用试金石；收错则亏钱，提示“这一行，眼睛就是本钱”。
6. **第三位客人（钩子）**：一个蒙面人当下一只上锁木匣，不报名字，只说“三十日内必来赎”。匣子不许打开——**主线由此展开**。

## 2. 核心循环

```
开门 → 客人上柜 → 沟通/鉴定 → 估价/压价 → 写当票（活当/绝卖）
   ↓
库房管理 → 到期：赎回 or 死当 → 死当品上架/转卖/拍卖
   ↓
打烊 → 结账 → 旬末交息银 → 升级/事件 → 下一天
```

### 2.1 一天的节奏
- **辰时开门 → 酉时打烊**，约 8~12 位客人。
- 每天随机发生 1 个街面事件（捕快盘查、洋兵过街、庙会、米价暴涨）。

### 2.2 两种交易方式（核心新增）
| 方式 | 说明 | 收益/风险 |
|---|---|---|
| **活当** | 付当价（约值的3~5成），开当票，约定当期（初始30天）与月息 | 赎回：赚利息；不赎：死当，按实价处理，赚差价 |
| **绝卖** | 一次性买断（对应原版“收货”） | 即刻拥有，但出价要更高 |

- 原版“收货 → 卖出”的利润模型完整保留在**绝卖**里。
- **活当**带来延迟回报和“人情”线：客人会回来，故事在回访中推进。

## 3. 游戏机制详解

### 3.1 估价与压价（对标原版谈判）
- 每件物品有**真实价值**（隐藏）、**客人期望价**、**客人底线**。
- 玩家报价 → 客人反应（表情、台词）→ 可多轮压价，每轮会消耗客人的耐心值。
- **行话系统**：朝奉压价时要“贬货”，必须用当铺黑话（史实）：
  - 衣服 →“虫吃鼠咬，光板没毛”
  - 金器 →“淡金”，银器 →“潮银”
  - 字画 →“残破旧画”
  - 用对了行话：压价成功率提高，“字号信誉”不受影响；用错或不用：客人觉得你外行。

### 3.2 鉴定小游戏（对标原版鉴别假货，做成实体操作）
| 工具 | 用途 | 解锁 |
|---|---|---|
| 眼力（默认） | 看包浆、款识、针脚 | 开局 |
| 试金石 | 划痕比色，辨金银成色 | 开局 |
| 戥子（小秤） | 称重，识破灌铅银锭 | 第1旬 |
| 放大镜（洋货） | 看印章、钟表机芯 | 第2旬 |
| 《古玩辨伪图谱》 | 查瓷器款识年代 | 第3旬 |
| 打听（消息贩子） | 花钱查货的来路 | 第4旬 |

每件可疑物品有 1~3 个“破绽点”，玩家用对工具才能发现。

### 3.3 赃物与官府（对标原版安保）
- 每件物品有隐藏的 **“来路”** 属性：清白 / 来路不明 / 赃物 / 禁物。
- **捕快盘查**事件：随机抽查库房，搜出赃物会面临：
  - 罚银
  - 行贿（花钱免灾，但钱庄和县衙快班捕快会记下你“好说话”）
  - 交出客人姓名（官府好感上升，江湖名声下降）
- **禁物**：鸦片烟枪、洋枪、维新党书信——收了利润高，被查到可能直接导致游戏结束。

### 3.4 怀揣“密物”的客人（对标原版流氓AI客人）
原版里有些客人身上带着流氓AI，要靠玩家识破；我们改成**身份可疑的客人**：
- 外表看是普通人，但对话里有破绽（口音、手茧、说错典故、身上的东西不合身份）。
- 身份类型：维新党人、义和团探子、洋行买办的眼线、宫里流出来的太监。
- 玩家选择：**收留帮他 / 报官领赏 / 装糊涂**，三种选择分别推动不同主线分支。

### 3.5 声望双轨
- **字号信誉**（正道）：影响正经客人和大宗买家，信誉高才能接官宦人家的高价货。
- **江湖名声**（偏门）：影响黑市渠道，名声高才能接到夜里上门的“夜当”。
- 两条声望大致互斥，最终决定结局走向。

## 4. 进度系统：逐级递增

### 4.1 时间结构（对标原版“每7天涨一次房租”）
- **1旬 = 10天**，旬末交息银。
- **一章 = 一个节令**，节令日是大结账日（钱庄要连本带息）：

| 章 | 节令 | 时代事件 | 息银 / 节令大账 | 新解锁 |
|---|---|---|---|---|
| 一 | 清明 | 铺子初接手 | 30 → 40两 / 首期借据300两（不在本章还本） | 基础鉴定、活当 |
| 二 | 端午 | 戊戌变法（百日维新） | 60 → 90两 / 600两（胡二爷出示伪造补页，总债变3000两） | 洋货品类、戥子 |
| 三 | 中秋 | 戊戌政变、六君子遇害 | 100 → 150两 / 1200两 | 夜当、密物客人 |
| 四 | 年关 | 义和团兴起、米价飞涨 | 180 → 250两 / 2500两 | 拍卖死当、雇伙计 |
| 五 | 庚子 | 八国联军入津（终章） | 战乱抢掠，无固定息银 | 保库存活，各路结局 |

### 4.2 物品与进度强关联
物品池按章节**解锁、换代**，物品本身就是在讲时代：
- **第一章：民生物**——棉袍、铜盆、银簪、旧书。教学为主，利润薄。
- **第二章：洋货涌入**——怀表、洋布、煤油灯、西洋镜。新货的真假更难辨。
- **第三章：没落旗人**——鼻烟壶、翎管、朝珠、扳指。值钱，常有赝品。
- **第四章：宫里流物**——官窑瓷、御赐如意、内务府旧档。利润极高，赃物率也高。
- **第五章：乱世**——洋枪、军饷银锭、教堂圣器、逃难人家的祖传之宝。

### 4.3 铺子升级（对标原版店面升级）
- **柜台**：高柜（威势+，客人更好压价）
- **库房**：防潮（字画不发霉）、防鼠、防火、暗格（藏禁物）
- **人手**：学徒（帮你初步分类）、账房（自动结算利息）、护院（防抢）
- **门面**：挂幌子、换匾额，提升字号信誉，吸引更高阶客人

## 5. 客户系统

### 5.1 职业图鉴（每种职业有固定的物品倾向、说话方式和破绽）
| 职业 | 常带物品 | 性格 / 沟通特点 | 可能的“鬼” |
|---|---|---|---|
| 车夫/苦力 | 棉袄、铜钱串、工具 | 急用钱，不太还价 | 偷来的东家物件 |
| 没落旗人 | 鼻烟壶、扳指、朝珠 | 死要面子，讨厌“当”字，要说“借” | 以赝品充祖传 |
| 戏班名角 | 戏服、头面、金钗 | 爱讲排场，情绪多变 | 欠了赌债 |
| 洋行买办 | 怀表、洋酒、西装 | 中英夹杂，精明 | 走私货 |
| 小脚太太 | 首饰、嫁妆 | 偷偷来当，怕夫家知道 | — |
| 烟鬼 | 什么都当 | 手抖、哈欠连天 | 多为偷窃 |
| 太监 | 宫中器物 | 尖嗓、出手阔绰 | 盗出宫的宝物 |
| 落第书生 | 字画、砚台、书 | 酸文假醋，爱讲典故 | 维新党人 |
| 江湖郎中 | 药材、人参、鹿茸 | 能说会道 | 假人参 |
| 洋教士 | 圣器、西书 | 中文生硬 | — |

### 5.2 对话系统
每位客人的对话分三个阶段：
1. **来意**：客人自述（可能说谎）。
2. **盘问**：玩家从 3~4 个问题里选（“这物件哪儿来的？”“家里几口人？”“急用钱为何？”），**问得越多客人越不耐烦**。
3. **议价**：报价、用行话、加减价。

**破绽判断**：客人说的话与物品、外貌、职业之间是否对得上。
> 例：自称“祖上是镶黄旗”，却把翎管说成“帽子上的笔管”——此人是骗子。

### 5.3 回头客与人情链（新增，因为有“赎当”机制才成立）
- 典当的客人会在当期内**回来赎当**，带来后续剧情。
- 例：小脚太太当了嫁妆金镯 → 第二旬回来哭诉赎不起 → 选择宽限 / 坚持死当 → 第四章她成了大户人家的掌家太太，回报你（或报复你）。
- 每章安排 3~5 条人情链，构成玩家的“熟客”系统。

## 6. 主线与结局
- **主线悬念**：师父的死、缺失的三页账本、蒙面人的木匣（内藏光绪朝密诏 / 内务府账册，具体由路线决定）。
- **结局（由双声望 + 关键选择决定）**：
  1. **百年老号**：还清债务，字号信誉高，恒裕当成为天津名号。
  2. **黑市枭雄**：江湖名声高，掌控南市地下买卖。
  3. **义士**：保护维新党人或保住密诏，铺子被抄，留名青史。
  4. **卖主求荣**：报官领赏，富贵但众叛亲离。
  5. **破产**：交不起息银，被钱庄收走铺子（对标原版失败结局）。
  6. **庚子劫灰**：终章没守住库房，铺子在战火中焚毁。

## 7. 美术与音效方向（晚清风格）
- **画面**：像素风（对接仓库现有 `pixel-art/pawnshop-icons`），色调为旧纸黄、乌木黑、朱砂红。
- **视角**：从高柜台**俯视**客人，客人只露半身，体现当铺的威势。
- **UI**：当票、算盘、印章、毛笔字；铜钱和银两作为货币图标。
- **音效**：算盘声、戥子碰撞、更夫梆子、街头叫卖、天津快板式的节奏 BGM。

## 8. 开发方案（对接仓库 Unity 工程）

### 8.1 里程碑
| 阶段 | 目标 | 周期（建议） |
|---|---|---|
| **M0 原型** | 单日循环：客人→鉴定→议价→结账；3种物品、2种客人 | 3~4周 |
| **M1 垂直切片** | 完整第一章（清明）：活当/赎当、旬息、行话、10种职业、30件物品 | 6~8周 |
| **M2 系统完善** | 第二、三章，赃物/官府、密物客人、铺子升级、双声望 | 8~10周 |
| **M3 内容填充** | 全5章、人情链、全部结局、约150件物品 | 10~12周 |
| **M4 打磨发布** | 平衡性、本地化、Steam 页面、Demo | 6周 |

### 8.2 数据驱动结构（用 ScriptableObject 或 JSON 配置）
```
ItemData      : id, 名称, 品类, 章节, 真实价值, 成色, 真伪, 来路, 破绽点[], 鉴定工具[]
CustomerData  : id, 职业, 外观, 物品倾向[], 耐心, 说谎率, 对话树, 人情链id
PawnTicket    : 物品, 当价, 月息, 当期, 客人id, 状态(活当/已赎/死当)
ChapterData   : 节令, 息银曲线, 解锁物品池, 解锁工具, 时代事件[]
Reputation    : 字号信誉, 江湖名声, 官府好感
```

### 8.3 数值平衡要点
- 当价 = 真实价值 × 30%~50%；月息 2%~3%（参照清代当铺月息）。
- 死当率控制在 40% 左右，让“利息收入”和“死当转卖”两种收益都成立。
- 息银增速略高于玩家正常收入增速，**逼玩家冒险收高利润的可疑货**——这正是原版最核心的张力，必须保留。

## 9. 一句话定位
> **“在大清最后的十几年里，坐在高柜台后面，给一个时代估价。”**
