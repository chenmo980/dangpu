- [ ] **T1 买卖客系统**（玩法对标 §4）：25% 客人为求购客，求购柜上/陈列中物品。UI 区分：求购客金色「求购」标签+按钮组切换（要价150%/120%/100%），卖出赃物同样 +10 罪证。验收：买/卖客都能完整成交，标注清晰。
- [ ] **T2 日夜场景**：打烊后场景切换为夜景层（bg/fg _flat_night_hd 已有），开张切回日景。验收：打烊弹窗期间背景为夜景。

## 4. 每轮任务固定流程（接力 AI 必读）

1. 读 `docs/迭代日志.md`（本轮接力状态）→ 认领清单中**第一个未勾选**任务。
2. 实现（改 `prototype/index.html`；大改前先跑一次 5 天模拟确认基线不炸）。
3. 验证（§5 协议）→ 失败必须修复或回滚，**不留红**。
4. 更新 `docs/迭代日志.md`（勾选任务、记录要点与遗留）→ `git commit` → `git push`。
5. 单轮时间盒 ~35 分钟；到点哪怕没做完也先提交可编译状态。
